🚲 Predictive Maintenance for Public Bike Sharing System
 👩‍💻 Project by: Kritika  
 🧠 Domain: Artificial Intelligence / Predictive Analytics  
🗓️ Year: 2025  
---
📌 Overview
This project predicts maintenance needs for a (Public Bike Sharing System) using operational data such as battery level, motor temperature, distance covered, and chain wear.  
It also visualizes the fleet’s health through a **real-time maintenance dashboard** showing *Low, Medium,* and *High Risk* bikes.
---
📊 Features
🚲 Simulated dataset for 20+ smart bikes  
🧠 Risk prediction (Low/Medium/High)  
💻 Interactive ASCII dashboard (C++)  
🖼️ Exportable dashboard image (optional Python script)  
📈 Top 10 risky bikes visualization  
---

## 🧩 Dataset
**File:** `bike_maintenance_data.csv`

| Column | Description |
|--------|-------------|
| Bike_ID | Unique identifier for each bike |
| Total_Rides | Number of rides completed |
| Avg_Ride_Duration(min) | Average ride duration |
| Battery_Level(%) | Current battery charge |
| Motor_Temperature(°C) | Current motor temperature |
| Distance_Covered(km) | Total distance covered |
| Last_Service_Days_Ago | Days since last maintenance |
| Brake_Efficiency(%) | Brake system efficiency |
| Tire_Pressure(psi) | Tire pressure level |
| Chain_Wear(%) | Chain wear percentage |
| Predicted_Risk | Predicted maintenance risk level |
